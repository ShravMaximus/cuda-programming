# GPU Computing & CUDA Programming

A collection of projects exploring **GPU architecture, parallel computing, CUDA programming, and performance optimization**, with a focus on understanding and improving GPU execution efficiency.

## Projects

| Project | Focus |
|---|---|
| **Project 2 — CUDA Kernels** | GPU kernel development and parallel computation using CUDA |
| **Project 3 — Warp Scheduling** | GPU warp scheduling strategies, simulation, and performance analysis |
| **Project 4 — GPU Performance** | GPU execution efficiency, compute units, and Tensor Core workloads |
| **Project 5 — Instruction Optimization** | GPU assembly analysis, instruction transformations, and optimization techniques |

## Technical Focus

- **Parallel Computing:** Developing and evaluating GPU kernels using CUDA C/C++.
- **GPU Architecture:** Exploring warp scheduling, execution pipelines, and hardware utilization.
- **Performance Engineering:** Analyzing GPU workloads and architectural trade-offs.
- **GPU Simulation:** Investigating scheduling strategies and execution behavior using simulation frameworks.
- **Low-Level Optimization:** Working with GPU assembly instructions and transformation techniques.

## Technology Stack

`CUDA` · `C++` · `Python` · `GPU Architecture` · `SASS` · `Performance Simulation`

## Overview

These projects demonstrate practical experience across multiple layers of GPU computing, from CUDA kernel development to architectural simulation and instruction-level analysis.

The emphasis is on understanding how GPU hardware executes parallel workloads and how software-level decisions influence computational performance.
